# The-Final-Anti-Cheat
Welcome to  The Final Anti-Cheat project!
This project is all about creating a powerful enough Anti-Cheat to stop hackers and cheaters with lots of host tools and administrative lists. 

The mod's Anti-Cheat has a giant arsenal of scanners for cheats invalid RPCs  a live chat translator.Admin ranks that can kick ban send rules game summary check id list (not tested yet). There also are VIP ranks but they are cosmetic. 
The Anti-Cheat can block hijack packets show ping fps trackers and lobby timer. Something unique about this mod is that it has a built-in ping and fps shocker. What does it do? It checks all player's ping trackers and if their ping goes above 350 the mod immediately sends an RPC packet to improve the handshake between that player and the host, the fps shocker just turns off special effects or other fps draining stuff on that player's screen if the fps is super low (around 30? if I'm not wrong?). 
The Anti-Cheat is supposed to have a custom loading screen( in the main menu) plus custom backgrounds. Custom tab for the Anti-Cheat settings a music player (yes the Anti-Cheat settings are so big that they are split between 2 cfg files so yeah) the mod has a ban list ImmunePlayers list where you put the friend codes of admins. a DenyName list a word kicker and 
another unique feature ! A censorer! 
What does it do? it checks words send in the chat and if that word is present in the censored word list it turns that word into stars. Perfect way to stop player's who trash talk other players for catching them.
